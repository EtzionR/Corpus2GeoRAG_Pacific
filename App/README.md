# GeoAI: From Corpus into GeoRAG 🌍

An interactive Geospatial Intelligence and Agentic RAG platform built with **Streamlit** and **Folium**. It translates natural-language queries into knowledge graph traversals, entity geocoding, and dynamic visual map overlays.

## Features ✨
- **Presentation Design Fidelity:** Matches the dark space / starry background and clean vector map presentation style.
- **Folium Interactive Maps:** Multi-layer interactive maps with custom radar markers, bounding boxes, and territorial control callout annotations.
- **Agentic RAG Pipeline:** Translates queries to entity extraction (NER), knowledge graph traversals, and dynamic visual coordinates.
- **Full Demo Queries Supported:**
  1. 🎯 *Show me where drone attacks took place.*
  2. ⚔️ *Show me places where battles took place.*
  3. 📍 *Who currently controls Kherson?*
  4. 🌐 General queries for any geocoded entities and locations.

## Quick Start 🚀

1. **Activate Virtual Environment & Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Streamlit Application:**
   ```bash
   streamlit run app.py
   ```
