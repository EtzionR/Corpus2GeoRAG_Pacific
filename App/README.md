# Corpus2GeoRAG: Pacific Theater (WWII) 🌊

An interactive Geospatial Intelligence and Agentic RAG platform built with **Streamlit** and **Folium**, applying Knowledge Graph extraction and geospatial reasoning strictly to the **World War II Pacific Theater** (Asia, Oceanic, and Maritime campaigns).

## Features ✨
- **Presentation Design Fidelity:** Matches the dark space / starry background and clean vector map presentation style.
- **Folium Interactive Maps (Pacific Centered):** Multi-layer interactive maps with custom radar markers, bounding boxes, and territorial control callout annotations centered on the Pacific Ocean and East Asia.
- **Agentic RAG Pipeline:** Translates natural-language queries into entity extraction (NER), knowledge graph traversals, and dynamic visual coordinates for the Pacific War.
- **Core Pacific Theater Demo Scenarios:**
  1. 🎯 **Strategic Air & Naval Strikes:** Visualizes major aerial campaigns (Pearl Harbor, Tokyo B-29 Firebombing, Hiroshima & Nagasaki Atomic Bombings, Truk Lagoon, Darwin, Rabaul) with animated radar concentric markers.
  2. ⚔️ **Major Pacific Battles & Theaters:** Delineates key naval and island combat zones (Battle of Midway, Guadalcanal Campaign, Battle of Leyte Gulf, Battle of Okinawa, Iwo Jima, Coral Sea, Saipan, Manila) with bounding box polygons and interactive pins.
  3. 📍 **Territorial Control & Liberation Callouts:** Identifies historical status, occupation phases, and liberation milestones (e.g. Liberation of Manila on March 3, 1945, Capture of Okinawa, Securing Guadalcanal, Fall and Liberation of Singapore).
  4. 🌐 **Pacific Knowledge Graph Geocoding:** Natural-language exploration of Pacific fleet bases, atolls, and island airfields.

## Quick Start 🚀

1. **Activate Virtual Environment & Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Streamlit Application:**
   ```bash
   streamlit run app.py
   ```
